# 当前进度说明

更新时间：2026-05-10

## 项目定位

`nfi-alpha-strategy` 是独立于上游 `NostalgiaForInfinity` 的长期策略研发仓库。当前主线已经从“完全手工重写 NFI”调整为更稳的方式：

1. 保留 NFI 原版策略作为可替换上游。
2. 用包装策略继承原版 NFI。
3. 只在包装层增加我们的风控、持仓时长控制、恢复退出等优化。
4. 后续上游 NFI 更新时，优先替换原版 `NostalgiaForInfinityX7.py`，再验证包装层是否仍然正常。

这样做的好处是维护成本低，避免每次 NFI 更新都要手工同步大量复杂逻辑。

## 当前判断

`max_open_trades=2` 的包装版收益极高，但主要原因之一是 `stake_amount = unlimited` 叠加更少开仓槽位后，单仓资金占比更大，复利被显著放大。它不是天然更稳，而是更集中。

更稳健的候选是 `max_open_trades=4` 的 RecoveryCutGentle 包装版：收益仍然非常高，同时最大水下比例和持仓时间更健康。
