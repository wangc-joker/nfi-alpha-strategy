# 0014 风险与持仓时长优化实验

## 目标

在 `refactor_base` 的 NFI 重构策略基础上，不改变现有杠杆，优先降低：

- 单笔最大浮亏，即 MAE / Maximum Adverse Excursion。
- 最长持仓时间，避免一个币长期被套。
- 账户最大回撤。

本阶段允许接受少量亏损，不再追求 100% 胜率。

## 回测环境

- 策略基线：`NFIRefactorStrategy`
- 优化策略文件：`strategies/NFIRiskDurationStrategy.py`
- 回测区间：`20251016-20260415`
- 初始资金：`302.6 USDT`
- `max_open_trades`：`2`
- 交易模式：Binance USDT futures isolated
- 配置：`D:\test\ft_userdata\user_data\config.backtest.dynamic.top40.302u.max2.halfyear.balanced.linear.json`

说明：临时 linear 配置只是在原回测配置上增加 CCXT 的 `fetchMarkets: ["linear"]`，避免 Binance `dapi` 交割合约接口网络失败；策略逻辑、币池、资金、开仓数不变。

## 实验版本

| 策略 | 主要改动 |
| --- | --- |
| `NFIRiskDurationBalancedStrategy` | 加 -18% 硬退出、21 天 grind 超时、45 天最长持仓 |
| `NFIRiskDurationStrictStrategy` | 加 -12% 硬退出、10 天 grind 超时、21 天最长持仓 |
| `NFIRiskDurationFilteredStrategy` | 屏蔽 ZEC/CRV/ETH 的 `120` grind 入场 |
| `NFIRiskDurationNoGrind120Strategy` | 屏蔽所有 `120` grind 入场 |
| `NFIRiskDurationLowMaeStrategy` | 屏蔽 `120`，并屏蔽 RIVER 的 61/62/63 与 UNI 62 |
| `NFIRiskDurationSelectiveStrategy` | 在 LowMae 基础上，继续屏蔽回测中亏损最集中的少数 pair/tag 组合 |

## 结论

`NFIRiskDurationSelectiveStrategy` 是本轮最佳平衡点。

它相比原始重构版：

- 收益从 `580.90%` 降到 `409.62%`，仍然很高。
- 最大浮亏从 `-73.08%` 降到 `-14.19%`，达到 15% 以内目标。
- 最长持仓从 `93d 18h 25m` 降到 `1d 11h 5m`。
- 胜率从 `100%` 降到 `98.18%`，接受了 1 笔亏损。
- 账户最大回撤从回测口径的 `0%` 变为 `6.64%`，这是因为策略不再一直等回本，而是允许及时认亏。

关键发现：单纯增加硬止损或超时退出不够。真正降低 MAE 的关键，是在入场前过滤高风险的 pair/tag 组合，尤其是 `120` grind 入场。

## 后续建议

- 用 1 年和 3 年数据验证 `Selective` 是否过拟合最近半年。
- 把 pair/tag 黑名单改成可配置参数或独立风险过滤模块，避免写死在策略类里。
- 对 `120` grind 不是永久删除，而是后续加市场状态过滤，只在更强趋势条件下允许进入。
