profit_current_stake_ratio：相对当前剩余仓位价值的收益率；
profit_init_ratio：相对第一笔入场成本的收益率。

## Hold Trades Runtime 迁移

本轮新增模块：

```text
nfi_refactor/state/hold_trades.py
```

迁移内容：

```text
get_hold_trades_config_file
load_hold_trades_config
_should_hold_trade
```

说明：

```text
hold-trades 是 NFI 给实盘/模拟盘使用的人工持仓保护机制。
当 runmode 是 live 或 dry_run，并且 hold_support_enabled 开启时，
策略会读取 nfi-hold-trades.json 或旧路径 hold-trades.json，
然后根据 trade id 或 pair 配置，决定某笔交易是否必须继续持有到指定利润阈值。

回测和 hyperopt 模式下，_should_hold_trade 会直接返回 False。
所以这块迁移对当前回测收益不应该产生影响，但它会影响实盘退出确认链路。
```

路径处理：

```text
优先使用 config["user_data_dir"] / "nfi-hold-trades.json"，这也是原版 NFI 推荐的新路径。
旧路径 hold-trades.json 仍作为兼容 fallback。
为了避免模块抽离后 __file__ 指向 nfi_refactor/state/hold_trades.py，
fallback 路径使用当前策略类所在文件目录，而不是 hold_trades.py 自己所在目录。
```
