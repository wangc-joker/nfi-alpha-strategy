# 0001 最小策略骨架

## 目标

建立第一版可加载的 `AlphaRegimeStrategy`，验证工程结构和插件化方向。

## 本阶段包含

- 主策略类：`AlphaRegimeStrategy`
- 市场状态模块：`MarketRegime`
- 风险过滤模块：`RiskManager`
- 退出模块：`ExitManager`
- 状态持久化模块：`StateStore`
- 第一个入场插件：`TrendPullbackSignal`

## 当前策略思想

只做多头。

第一版只交易上涨趋势中的回调：

- 价格在 EMA50 上方。
- 价格回调到 EMA20 附近。
- RSI 不极端。
- 成交量不能过低。
- ATR 波动率不能过高。

## 暂不包含

- 补仓。
- 动态杠杆。
- FreqAI。
- 多周期 BTC/ETH 过滤。
- NFI 风格复杂利润缓存。

## 下一步

把策略同步到 Freqtrade 的 `user_data/strategies`，跑一次最小回测，确认能正常加载。

## 2026-04-25 烟测结果

测试命令：

```powershell
docker compose run --rm freqtrade backtesting --config /freqtrade/user_data/config.backtest.alpha.futures.smoke.json --strategy-path /freqtrade/user_data/strategies --strategy AlphaRegimeStrategy --timerange 20260401-20260410 --timeframe 5m
```

测试区间：

```text
2026-04-01 00:00:00 -> 2026-04-10 00:00:00
```

测试交易对：

```text
BTC/USDT:USDT
ETH/USDT:USDT
SOL/USDT:USDT
```

结果摘要：

```text

最终资金：298.330 USDT
```

结论：

第一版策略骨架已经可以被 Freqtrade 加载并完成回测。当前信号质量还没有优化，收益为负是可接受的阶段性结果。下一阶段重点不是追收益，而是加入更强的市场状态过滤和更合理的退出结构。
