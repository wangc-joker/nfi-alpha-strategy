# 0015 非币种硬编码风险过滤实验

## 目标

用户要求降低过拟合风险，不再依赖特定币种黑名单，例如不要写死 ZEC、RIVER、UNI 等币种。

本轮实验改用：

- top20 币池，而不是 top40。
- 1.5 年回测区间：`20241015-20260415`。
- 初始资金：`302.6 USDT`。
- `max_open_trades`: `2`。
- 杠杆保持原策略逻辑，不做额外修改。

## top20 币池

使用 top40 中本地有历史数据的前 20 个币，排除了没有本地历史数据的币，避免缺数据影响结果。

```text
BTC, ETH, SOL, XRP, ZEC, DOGE, TAO, HYPE, BNB, RIVER,
ADA, SUI, AVAX, ENA, LINK, DOT, AAVE, NEAR, FIL, BCH
```

## 新增非币种硬编码版本

| 策略 | 是否币种硬编码 | 核心逻辑 |
| --- | --- | --- |
| `NFIRiskDurationNoGrind120Strategy` | 否 | 屏蔽所有 `120` grind 信号 |
| `NFIRiskDurationDynamicGuardLooseStrategy` | 否 | 宽松市场压力过滤，不屏蔽 `120` |
| `NFIRiskDurationDynamicGuardStrategy` | 否 | 中等市场压力过滤，不屏蔽 `120` |
| `NFIRiskDurationDynamicGuardStrictStrategy` | 否 | 严格市场压力过滤，不屏蔽 `120` |
| `NFIRiskDurationSignalGuardLooseStrategy` | 否 | 屏蔽 `120` + 宽松市场压力过滤 |
| `NFIRiskDurationSignalGuardStrategy` | 否 | 屏蔽 `120` + 中等市场压力过滤 |
| `NFIRiskDurationSignalGuardStrictStrategy` | 否 | 屏蔽 `120` + 严格市场压力过滤 |

说明：屏蔽 `120` 是信号级别处理，不是币种级别硬编码。这个规则来自跨币种风险特征：`120` grind 在多轮回测中反复贡献最长持仓和最大浮亏。

## 结论

### 最佳综合版本

`NFIRiskDurationSignalGuardLooseStrategy`

原因：

- 不再使用任何特定币种黑名单。
- 收益率 `11034.55%`，非常接近原版 `11831.17%`。
- 账户最大回撤从原版 `36.83%` 降到 `8.04%`。
- 最长持仓从原版 `151d 19h 20m` 降到 `1d 4h 30m`。
- 最大浮亏从 `-112.83%` 降到 `-47.25%`。

它没有达到 15% MAE 目标，但比硬编码 Selective 更干净，且收益、回撤、持仓时间的综合表现更好。

### 风险优先版本

`NFIRiskDurationSignalGuardStrategy`

原因：

- 不使用币种硬编码。
- 最大浮亏降到 `-20.70%`。
- 账户最大回撤 `7.39%`。
- 最长持仓 `19h`。

缺点是收益率下降到 `473.38%`，明显牺牲收益。

## 为什么非硬编码版本仍难以压到 15% MAE

最差 MAE 来自 2025-02-03 的快速闪崩类行情，例如 XRP/BNB 在入场后 15-20 分钟内快速下插。此类风险靠入场前的 BTC 状态、波动率、成交量过滤不一定能提前识别。

如果目标必须稳定压到 15% 内，后续更合理的方向不是继续加币种黑名单，而是：

- 实盘使用交易所止损，降低闪崩期间的实际滑落。
- 限制单笔风险敞口，而不是只看策略信号。
- 对高波动日降低首仓仓位。
- 将 `120` grind 做成市场状态许可，而不是永久屏蔽。
- 使用更细粒度数据或真实订单簿模拟评估闪崩风险。
