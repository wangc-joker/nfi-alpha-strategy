# 0011 NFI 重构决策

## 决策

项目路线从“参考 NFI 从零设计”调整为：

```text
以 NFI 为参考实现进行模块化重构。
```

## 原因

从零设计的优点是结构清晰，但目前暴露出几个问题：

```text
入场信号质量不足；
调试周期长；
短期难以达到 NFI 的成熟度；
很多 NFI 的保护逻辑很难靠猜测复现；
```

因此更合理的路线是：

```text
先对齐 NFI；
再改造 NFI；
最后调优；
```

## 新阶段定义

当前进入：

```text
NFI 重构阶段 1：Parity 基础建设
```

下一阶段：

```text
NFI 重构阶段 2：结构化拆分
```

## 暂停事项

旧的 `AlphaRegimeStrategy` 不删除，但从现在开始定位调整为：

```text
实验沙盒；
模块验证场；
新想法快速试验区；
```

正式追求高收益和低回撤的主线，改为：

```text
NFIRefactorStrategy
```

## 当前行动

先完成：

```text
1. 记录 NFI 原版固定回测结果；
2. 建立 NFIRefactorStrategy 目录结构；
3. 制定模块迁移清单；
4. 开始从指标层和保护层迁移；
```

## 判断标准

每一次迁移后都要回答：

```text
交易数是否接近？
收益是否接近？
最大回撤是否接近？
tag 分布是否接近？
多空数量是否接近？
```

只有这些接近，才说明重构没有破坏原逻辑。
