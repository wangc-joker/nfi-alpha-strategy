# 0008 多空市场权重框架

## 目标

策略不能只做多。

更合理的结构是：

```text
多头市场：多头信号权重高，空头信号权重低，空头必须质量很高才开。
空头市场：空头信号权重高，多头信号权重低，多头必须质量很高才开。
震荡市场：两边都可以做，但都要偏谨慎。
```

这不是简单开关，而是“市场状态影响开仓门槛和首仓仓位”。

## 当前实现

BTC 1h 市场状态：

```text
alpha_market_bias = 1   多头市场
alpha_market_bias = 0   中性市场
alpha_market_bias = -1  空头市场
```

首仓权重：

```text
多头市场：
long weight = 1.00
short weight = 0.35

空头市场：
long weight = 0.35
short weight = 1.00

中性市场：
long weight = 0.65
short weight = 0.65
```

质量门槛：

```text
多头市场：
long required quality = 5
short required quality = 7

空头市场：
long required quality = 7
short required quality = 5

中性市场：
long required quality = 6
short required quality = 6
```

## 新增空头信号

第一版空头信号：

```text
alpha_downtrend_bounce_short_v1
```

核心思想：

```text
币种处于下跌趋势；
价格反弹到 EMA20 附近；
但仍没有收复 EMA50；
RSI 短线偏热；
尝试做空弱反弹。
```

## 当前风险

第一版空头信号只是框架原型，不等于已经可实盘。

短区间初测显示，它在上涨区间容易拖累收益，所以后续必须继续收紧：

```text
空头只在 BTC 明确熊市时更积极；
BTC 非熊市时，空头需要更高 score；
空头退出逻辑需要单独优化；
```

## 第一轮失败实验

第一次直接启用“多空都可交易，靠质量门槛和仓位权重控制”后，3 个月回测明显失败。

区间：

```text
2026-01-15 到 2026-04-15
市场变化：-36.52%
```

结果：

```text
交易数：1876
收益：-162.892 USDT
收益率：-54.30%
胜率：20.3%
最大回撤：58.52%
```

失败原因：

```text
交易数过度膨胀；
中性市场和逆势方向放行太宽；
第一版空头信号质量不足；
```

因此主线改成更保守的安全版本：

```text
多头只在 BTC 多头状态开；
空头只在 BTC 空头状态开；
空头信号 min_score 提高到 60；
```

后续如果要实现“多头市场也允许极高质量空头”，必须额外设计反向信号专用高门槛，不能复用普通顺势信号。

## 第二轮收紧实验

收紧为：

```text
多头只在 BTC 多头状态开；
空头只在 BTC 空头状态开；
空头信号 min_score = 60；
```

3 个月结果：

```text
交易数：1089
收益：-116.659 USDT
收益率：-38.89%
胜率：20.2%
最大回撤：47.25%

多头交易：430
多头收益：-49.852 USDT

空头交易：659
空头收益：-66.807 USDT
```

结论：

第一版空头信号不能进入主线。

它不是略差，而是显著增加交易数和回撤。当前保留多空框架、市场权重、空头信号文件，但从 `AlphaRegimeStrategy.signal_modules` 中移除。

下一步应该重新设计空头信号，不再简单镜像多头回调逻辑。更合理的空头方向可能是：

```text
BTC 强熊趋势确认；
币种相对 BTC 更弱；
跌破横盘区间后反抽失败；
放量下跌后的低量反弹；
```
