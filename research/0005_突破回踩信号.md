# 0005 突破回踩信号

## 目标

阶段 3 的 `trend_pullback` 已经能在 Top30 动态币池中跑出正收益，但它本质上只有一种交易思想：趋势中的普通回调。

阶段 5 开始加入第二类可插拔入场模块：

```text
breakout_retest
```

它的目标不是追求更多交易，而是捕捉“放量突破后第一次健康回踩”的机会。

## 设计

新增文件：

```text
strategies/alpha_modules/signals/breakout_retest.py
```

新增入场标签：

```text
alpha_breakout_retest_v1
```

核心判断：

```text
最近 72 根 K 线的前高被突破
突破 K 线成交量大于 30 根均量的 1.2 倍
突破时 RSI14 处于 52 到 72
最近 18 根 K 线内出现过有效突破
当前价格回踩到 EMA20 附近
当前收盘价仍高于 EMA20 和 EMA50
当前 RSI14 处于 48 到 68
当前成交量不低于 30 根均量的 0.7 倍
```

## 与趋势回调的区别

`trend_pullback` 更像是：

```text
已经在上升趋势里，价格短线回落，尝试低吸。
```

`breakout_retest` 更像是：

```text
刚刚突破了一个区间，等第一次回踩确认后再尝试进入。
```

两者都走统一的主过滤：

```text
alpha_allow_long
```

所以新增信号不会绕过 BTC 市场状态、趋势质量、流动性和波动过滤。

## 验证要求

必须和阶段 3 的 Top30 基线对比：

```text
阶段 3 top30：
交易数：47
收益：+8.172 USDT
收益率：+2.72%
胜率：25.5%
最大回撤：2.77%
```

如果新增信号提高收益但明显扩大回撤，需要继续调退出逻辑。

如果新增信号没有贡献，或只贡献亏损交易，则保留代码但从 `signal_modules` 中移除，作为研究备选。

## 实测结果

同区间 Top30 复测：

```text
交易数：48
收益：-3.147 USDT
收益率：-1.05%
胜率：27.1%
最大回撤：4.18%
```

按入场标签拆分：

```text
alpha_breakout_retest_v1：
交易数：14
收益：-0.445 USDT
收益率：-0.15%
胜率：35.7%

alpha_trend_pullback_v1：
交易数：34
收益：-2.702 USDT
收益率：-0.90%
胜率：23.5%
```

## 结论

`breakout_retest` 第一版不进入主线。

原因不是它自己亏损特别大，而是它改变了资金占用顺序。在 `max_open_trades = 2` 的配置下，新信号会抢占仓位，使原本阶段 3 中更优的趋势回调交易无法成交，最终让整体收益从 `+2.72%` 降到 `-1.05%`。

保留文件：

```text
strategies/alpha_modules/signals/breakout_retest.py
```

但从 `AlphaRegimeStrategy.signal_modules` 中移除。后续如果继续研究突破类信号，需要先设计“信号优先级”或“信号资金桶”，不能让未验证的新信号直接和主信号抢仓位。
